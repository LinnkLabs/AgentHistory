# agent-history-cli

Convenience alias for **[`@getlinnk/agent-history`](https://www.npmjs.com/package/@getlinnk/agent-history)**.

```bash
npx agent-history-cli
```

Every agent session, one board — a local-first task board + searchable librarian for your Claude Code
and Codex sessions. Full docs, source, and screenshots:
**https://github.com/LinnkLabs/AgentHistory**
